Conectar Firebase
Esto activa el sync en vivo entre Mati y Vale.
Solo se hace una vez.
Pasos rápidos (5 min):
  1. Entra a console.firebase.google.com con tu cuenta Google.
  2. Click "Add project" → nombre depto205 → continuar (sin Analytics).
  3. Menú izq → Build → Realtime Database → Create Database → región más cercana → modo prueba ("test mode").
  4. Engranaje arriba izq → Project settings → baja a "Your apps" → click el ícono </> (Web) → registra app con nombre depto205.
  5. Copia el objeto firebaseConfig = {...} (todo el bloque entre llaves) y pégalo abajo.
  6. Comparte este archivo HTML con Vale: ella abre el mismo enlace y ya están conectados.
